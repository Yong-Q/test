# Student → POLAR 重加权的 ESS（2026-10-27）

**问题：** 用蒸馏后的 Plan D 学生（MACE-Polar 代理）做源采样，再一步重加权到
POLAR，能否恢复 POLAR 的 c₁/c₂？

**结论：不能在生产尺寸上用一步重加权。** 1,152 原子时 σ_β=8.0、ESS≈0.24 %
（501 帧里等效 1.2 帧），与 OFF→POLAR 同属 collapse；96 原子小体系
（σ_β=1.87、ESS≈44 %）和气相（σ_β=0.16、ESS≈98 %）才可用。正确路线是
**直接用学生采样、不加权**，或按
[验证计划 Task 6](superpowers/plans/2026-10-23-polar-c1c2-validation.md)
用 λ 中间势 + BAR/MBAR。

## 为什么学生的 ESS 反而更低

ESS 由**最大的几个权重**决定，不是 σ_β 的单调函数：

- 学生的 σ_β 更小（8.0 vs 13.8），说明它整体更接近 POLAR；
- 但 1,152 原子这批帧是 OFF23 采的，对学生是分布外；第 277 帧
  βΔU ≈ −22.9，单帧拿走 91.5 % 的权重；
- OFF23 不会在自己的轨迹上出现这种离群，所以它的最大单帧只有 59.6 %。

ESS 是尾部敏感统计量：单帧离群就能把它压到 1。相比之下 σ_β 更稳健。
这不表示学生更差；在它自己采的 96 原子系综上 ESS≈44 %。

## 尺寸效应

ΔU 是广延量。1,152 原子时逐帧涨落 0.207 eV，βΔU 的 σ 就是 8。要把
σ_β 压到 3 以下，每原子能量涨落需从 0.18 降到 ~0.07 meV/atom，还要再准
2.5–3 倍；这不是换采样器能解决的。两个 N 粒子系综的重叠随 N 指数衰减，
是重要性采样的固有困难。

## 与文献做法的差别

文献里重加权通常能工作，是因为它们满足至少一条：

1. 扰动小（温度/压力微调、alchemical λ 步、伞形采样去偏），而不是换哈密顿量；
2. 用中间态 + BAR/MBAR，而不是一步跳；
3. 样本量大（10⁵–10⁶ 帧），ESS 0.2 % 仍有 10³ 有效帧；
4. 观测量不随 N 广延（溶剂化自由能、局部环境），而不是整盒 c₁/c₂；
5. 先扣掉可解析的广延项（常数、线性密度/温度项、mean-field 修正）；
6. 体系小（~10² 原子），重叠本来就高。

本仓库的验证计划 Task 6 已把第 2、3、5 条列为正式步骤；Task 5 要求把 ESS
降级为诊断量，最终用逐观测量分块误差和独立 POLAR 参照判定。

## 与 TODO / 文献路线的关系

本报告只判定**一步重要性采样**（源=学生、目标=POLAR、同一批帧）在 1,152 原子
不可用；不推广为“所有状态点都不能重加权”，也不把它当作程序错误的证据。
[OFF→POLAR TODO](TODO_OFF_POLAR_2026-10-27.md) 里的 Δ学习/校正势路线
（MLPT 学 ΔU、MLMC 用 U_corr 重新采样、λ 中间势 + BAR/MBAR）正是提高重叠的
办法：先让新轨迹来自更接近 POLAR 的 U_corr，再对残差重加权。按 Task 6，这些
都需要**新的混合势采样**，不能只给旧帧补能量评分；并且混合势的能量和力必须
一致，最后用独立 POLAR 重评估检查残差。
