# 外势幅度和目标温度：501帧固定轨迹重加权边界扫描

**结论是这一批样本的敏感性，不是实际相变、模型精度或新温度/外势下MD验证。**

## 轨迹前段如何处理？

OFF23在生产前已有20 ps平衡；本次额外检查生产段0–500 ps。50 ps时间块以及细分前段显示：质心位于z两端20%区域的分子比例，0–5 ps为15.10%，5–10 ps为11.56%，10–20 ps为4.92%，20–30 ps为0.70%，30–50 ps为0.42%，50–100 ps为1.01%；同时整盒能量差均值由0–5 ps的480.142 eV变化到20–30 ps的480.909 eV。外势形状函数的均值也由−158.69变化到−232.00。

因此**将剔除生产前20帧、保留20–500 ps共481帧作为主要敏感性分析**，另提供0、5、10、30、50、100、200 ps截断。20 ps是依据有限诊断选取的工作假设，**不是已证明完全平衡的切点**；界面漂移、慢模态、目标分布重叠及独立轨迹仍需核查。保留的20 ps帧对应step=20000；之前额外的20 ps预平衡不应与生产时间混淆。

## q是什么，外势怎样进入？

相同温度下、源轨迹是无额外外场的OFF23、目标是POLAR加外势时：

```text
ΔU(x) = U_POLAR(x) − U_OFF23(x)
U_ext(x) = sum_m v_ext(z_m)
q(x) = exp[ −β × (ΔU(x) + U_ext(x)) ]
```

如果同一外势以相同形式同时作用源与目标，且温度相同，该外势在势差中抵消，不可再重复加入。本次只测试**源无此场、目标有此场**。

外势形状明确指定为 `v_ext(z)=A*cos(2πz/Lz)`，z为水分子质心、A单位eV/分子；整盒外势是A乘每帧所有384个cos值之和。改变cos相位、波长、局域壁面形式或分子取向会改变结果。本体系为界面分层轨迹，这个示例不是通用于所有外场的唯一边界。`A`可正可负，分别将不同位置变为低势区。注意振幅A的峰谷差为2|A|，每个分子实际场能是A cos，整盒场能是求和。

## 比较的“边界”是什么？

能量基准可任意移动；本报告比较去除时间均值后**跨帧标准差**，与重加权指数中的相对波动相关，而不是将480 eV平均值当有效势差。固定温度下定义：

```text
势差波动 = sd[ U_POLAR − U_OFF23 ]
外势波动 = |A| × sd[ sum_m cos(2π z_m/Lz) ]
边界 = 外势波动 / 势差波动 = 1
```

主要截断 `t≥20 ps`：势差波动0.341872 eV，形状函数标准差3.47045；等波动振幅为 **|A|=0.09851 eV/分子 = 3.811 kBT（300 K）**。外势振幅0.05/0.10/0.20 eV时，场波动与势差波动之比约0.508/1.015/2.030。上述是**整盒项的跨帧波动**，不是直接将单分子A与整盒能量差均值比较。具体结果及截断范围见[cutoffs.csv](cutoffs.csv)。

## 改变温度怎么计算？

源轨迹温度固定为T₀=300 K；相同N、V、势函数在源/目标分别为OFF23/POLAR时，目标温度为T，目标额外场为U_ext，构型权重比为：

```text
log q = β₀ U_OFF23 − βT (U_POLAR + U_ext)
      = (β₀ − βT) U_OFF23 − βT(ΔU + U_ext)
```

计算前对各项减去相应跨帧常数，防止原子能量零点和数值下溢污染结果；此处源/目标粒子数、质量和盒子不变，动量积分产生的与构型无关的因子在权重归一化后抵消。**不能把300 K轨迹的指数直接改为 −βT ΔU 并把它称为T的正确重加权**：该式缺少源温度变化项。

在 `t≥20 ps`、不加外场的样本中，若以 `sd[(β₀−βT)U_OFF23]` 与 **300 K下** `sd[β₀ ΔU]` 相等作为对照线，求得约 **247.14 K 和381.62 K**。如果比较的是目标T下的势差项 `βTΔU`，应使用网格中的 `ratio_temperature_to_gap_logweight_sd`，边界数值不同。温度项包含整盒能量波动，不能用每个原子的平均差。β的量纲和零点约定需一致。
