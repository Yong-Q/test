# c1所需密度：不同估计器试算（2026-10-28）

**定位：比较估计器的数值行为，不是POLAR密度准确度或c1标签认证。** 使用此前OFF23生成的501帧水轨迹、每帧的OFF/POLAR能量和分子质心，不重新运行MD，不计算目标力。目标权重Kish ESS=2.349，最大帧权重59.6%；没有独立POLAR目标轨迹。源引擎与OFF重算能量去常数后仍有约0.030 eV波动，未解决。

## 方法

固定300 K、384个水分子、周期盒、40个z区间，每个区间宽0.877 Å。每个方法积分均约为384个分子。密度是输入数据，还不是绝对c1；从密度到c1需要目标化学势、外场及理想参考的一致约定，固定N与界面平衡还需检查。

| 方法 | 每帧统计量/估计方式 | 状态 |
|---|---|---|
| OFF23 | 格内质心数，等帧平均 | 源轨迹诊断 |
| 直接重加权 | 格内质心数乘q，同帧分子分母 | 基线；ESS 2.349，未认证目标精度 |
| 空间平滑 | 对直接重加权密度做周期高斯平滑，σ=0.877 Å | 改变空间分辨率和产生平滑偏差；不是更高ESS |
| 条件平均能量差 | 根据格内质心出现的次数，对帧能量差做占有数加权平均，只保留均值项 | 模型近似，有潜在偏差 |
| 条件高斯能量差 | 上述条件均值及方差假设高斯，保留均值与方差项 | 模型近似；不保证条件分布高斯，也不保证目标重叠 |

后两种方法借鉴[2026预印本的条件能量差思想](https://arxiv.org/abs/2605.15630)，但该文的演示是伞形采样反应坐标PMF；此处使用多分子一体密度，是独立试验，不视为对其方法的复现或论文背书。

定义n[i,k]是第i帧第k格质心数，gap[i]是同帧POLAR−OFF总能量。条件均值和方差使用 `n[i,k]` 加权，而非把一个多分子帧简单地按是否非空取一次。采用统一的全局能量常数平移并用log域归一化；各空间格再统一归一化到固定N。注意：最后的归一化不保证近似剖面的每一格都符合源样本中见过的构型支持。

## 结果：直接比较与适用范围

- 取源密度和直接重加权密度均不低于0.005分子/Å³的23个格，前250帧和后251帧密度差的RMS：直接重加权0.00934，平滑后0.00629分子/Å³。平滑让本数据的前后差更小，同时改变了空间分辨率；**无法据此认定更准确**。
- 20个连续时间块、200次块重采样的同一区域每格2.5–97.5百分位宽度中位数：直接0.01318，平滑0.00701分子/Å³。这只是有限轨迹的敏感性描述，未验证为95%覆盖概率；不能恢复缺失尾部，亦不是独立目标误差条。200次重采样中有78次没有包含最大权重帧。
- 全域上，条件均值近似把近100%的归一化密度集中到源密度低于0.005的区间；其峰值0.295分子/Å³对应单格约142个分子，而已有501帧该格每帧最多6个。条件高斯近似峰值约0.800分子/Å³，对应约384个分子，而该格已有帧最多7个。这些近似值超出**这批帧任何正权重平均的逐格范围**，应视为严重依赖模型外推，不代表目标真实密度必然不可能。
- 分母用501帧q、分子qA按每5帧取一个时，5种起始偏移的密度积分分别约570、0.70、180、1163、4.92个分子；真实固定N为384。结果由是否抽到高权重帧决定。若改用相同子集自归一化，积分代数上回到384，但并不能证明密度准确。这个固定轨迹内的稀疏抽样例子不否定更充分采样下多频率方法的可行性。
- 密度低区域一个bin的源计数1 ps滞后相关约0.60；同一份数据的q样本相关被极少数尖峰主导，不能据此认证q真实相关时间或直接修正ESS。详见[时间相关诊断](time_correlation.json)。
