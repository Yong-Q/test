# 外场扰动幅度 vs OFF–POLAR 模型差（2026-10-28）

问题：外场通过 `exp(-βV_ext)` 进入 q。多大的外场幅度，其逐帧能量扰动
可以和 OFF–POLAR 的模型差相当？

数据：501 帧轨迹的前 120 帧（1,152 原子，300 K）；模型差基准
`std(ΔU_OFF-POLAR) = 0.356 eV`（整盒）。

## 结论

- **site field**：幅度标度 **s ≈ 0.4–0.6**（即 a·kT 里 a 的 0.4–0.6 倍）
  时，场扰动与模型差同量级；当前采样用 s=1，场扰动约 0.6–1.0 eV，
  是模型差的 **1.6–2.8 倍**。
- **均匀场**：**E ≈ 0.15 V/Å** 时同量级；E=0.1 约 0.7 倍，E=0.2 约 1.35 倍。
- 三个 seed 的 site field 在同幅度下相差约 1.8 倍（0.28–0.51 eV @ s=0.5），
  所以“同量级”的窗口应理解为 **0.2–0.7 eV**，而不是单点。

## 对采样的含义

- 场扰动大于模型差，说明外场确实在驱动结构（好事：探索新构型）；
- 但重加权时若场相同，场能整体抵消，限制蒸馏的仍是模型差本身；
- 若要用“场幅度”作为扰动强度，建议覆盖 s = 0.25 / 0.5 / 1 / 2 四档
  （或均匀场 0.05 / 0.1 / 0.2 / 0.5 V/Å），这样从“小于模型差”到
  “大于模型差”都有数据。

## 温度维度

β = 1/(k_BT)，所以同样的能量扰动在不同温度下的无量纲幅度不同：

| T (K) | k_BT (meV) | 模型差 σ_β (0.356 eV) | site s=1 σ_β (0.85 eV) | 均匀场 0.1 V/Å σ_β (0.24 eV) | σ_β=1 的 site 幅度 | σ_β=1 的 E (V/Å) |
|---:|---:|---:|---:|---:|---:|---:|
| 300 | 25.85 | **13.76** | 32.9 | 9.3 | 0.030 | 0.011 |
| 500 | 43.1 | 8.26 | 19.7 | 5.6 | 0.051 | 0.018 |
| 700 | 60.3 | 5.90 | 14.1 | 4.0 | 0.071 | 0.025 |
| 1000 | 86.2 | 4.13 | 9.9 | 2.8 | 0.101 | 0.036 |

要点：

1. **固定物理幅度（eV）时，温度越高 σ_β 越小**：同样的 0.356 eV 模型差，
   300 K 是 13.8，1000 K 降到 4.1。高温重加权更容易。
2. **JCTC 约定是 V/kT = Σ a sin(...)，即物理幅度本身 ∝ T**。按这个约定，
   `σ_β` 与温度无关（a 固定时），外场的物理强度随 T 增大。
   两种约定不要混用。
3. 上表的模型差 0.356 eV 是 300 K 轨迹测的；温度变化时 ΔU 的分布也会变，
   严格做其它温度需要对应温度的轨迹。
4. 若要把“外场扰动 ≈ 模型差”作为设计目标：
   - 固定 eV 幅度：匹配条件 `std(ΔV)=0.356 eV` 与 T 无关；
   - 固定 JCTC 标度：`s ≈ 0.42` 在 300 K 匹配，其它温度需重新测 ΔU 分布。
