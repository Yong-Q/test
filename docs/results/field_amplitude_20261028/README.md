## 温度换算

- 固定物理幅度（eV）时，`σ ∝ 1/T`；例如 500 K 的 σ 是 300 K 的 0.6 倍。
- JCTC 约定 `V/kT = Σ a sin(...)` 时物理幅度 ∝ T，σ 与 T 基本无关。
- 本表只用 300 K 的轨迹；其它温度需要对应温度的轨迹重新测 std(ΔV)。
