# q 变体：外场幅度与温度（β）的对照（2026-10-28）

把每个采样/外场状态写成一个 q 变体 `q_i(V; β)`：
`q_i = exp(-β V_ext,i)`，β = 1/(k_BT)。第一列就是该 q 的 (V, β)。

基准是模型差 `q_model = exp(-β ΔU_OFF-POLAR)`，
`std(ΔU) = 0.3558 eV`（120 探帧，300 K）。

## 读法

- **σ_β = β·std(ΔV)** 是 q 的无量纲宽度；σ_β ≈ 1 时权重还比较平坦，
  σ_β ≳ 3 就开始集中，σ_β ≈ 14 就塌缩。
- `q2`（site 0.5 kT，300 K）与 `q_model` 同量级（0.43 vs 0.36 eV，σ_β 16.5 vs 13.8）；
- `q1` 和 `q6` 的扰动小于模型差（0.21/0.24 eV）；
- `q3`、`q7` 的扰动大于模型差（0.85/0.48 eV）；
- 同一物理幅度升到 500 K（β=23.2）时 σ_β 约降为 0.6 倍（q4 vs q2、q8 vs q6）。

## 结论

- 外场扰动与模型差同量级：site **V ≈ 0.4–0.6 kT**，均匀场 **E ≈ 0.15 V/Å**；
- 当前采样用 site V=1 kT，扰动是模型差的 **1.6–2.8 倍**；
- 温度通过 β 进入：同一 eV 幅度，T 越高 σ_β 越小；JCTC 的 `V/kT` 约定下
  物理幅度 ∝ T，σ_β 与 T 无关（两种约定不要混用）；
- 设计采样档位时建议让 q 的 σ_β 覆盖 1–30 的范围：site V = 0.25/0.5/1/2 kT，
  均匀场 0.05/0.1/0.2/0.5 V/Å，温度 300/500/700 K。
