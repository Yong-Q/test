## 结论

- **同量级窗口**（与模型差 0.356 eV 相比）：
  - site 四正弦：**s ≈ 0.4–0.6**（三个种子给出的窗口约 0.2–0.7 eV）；
  - 均匀场：**E ≈ 0.15 V/Å**（0.1 约 0.7 倍，0.2 约 1.35 倍）。
- 当前采样用 **s = 1**，场扰动约 0.57–1.01 eV，是模型差的 **1.6–2.8 倍**；
  种子间差异约 1.8 倍。
- **温度**：同一物理幅度下，σ_β ∝ 1/T。模型差 0.356 eV 在 300/500/700/1000 K
  的 σ_β 分别为 13.76 / 8.26 / 5.90 / 4.13；所以高温重加权更容易。
- **约定**：JCTC 的 site field 是 `V/kT = Σ a sin(...)`，物理幅度 ∝ T；
  按这个约定 a 固定时 σ_β 与 T 无关，外场物理强度随 T 增大。两种约定不要混用。
- 模型差 0.356 eV 本身是 300 K 轨迹测的；严格比较其它温度需要对应温度的轨迹。

## 建议的采样档位

- site field：s = 0.25 / 0.5 / 1 / 2，覆盖“小于/等于/大于模型差”；
- 均匀场：E = 0.05 / 0.1 / 0.2 / 0.5 V/Å；
- 温度：300 / 500 / 700 K 三档，配合上表判断 σ_β 落在 1–3 的“可用窗口”。
