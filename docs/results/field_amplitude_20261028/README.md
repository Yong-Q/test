## 读法

- `s` 是 JCTC 约定的幅度倍数（`V/kT = s·Σ a_n sin(...)`）；`s=1` 是 JCTC 默认。
- 与模型差同量级：**site s ≈ 0.4–0.6**；**均匀场 E ≈ 0.15 V/Å**。
- 当前采样 `s=1`：std(ΔV)=0.81 eV，是模型差的 **2.28 倍**；三个场种子的标准误约 0.11 eV。
- 温度：同一 eV 幅度，σ_β ∝ 1/T；`s=0.5` 从 300 K 的 15.7 降到 1000 K 的 4.7。
- 等效均匀场一列把 site 场换算成“同样扰动强度的均匀场”，方便和实验场强比较。
