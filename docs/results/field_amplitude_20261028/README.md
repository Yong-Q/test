## 温度说明

`std(ΔV_field)` 和 `std(ΔU_model)` 都乘同一个 `1/(kB T)`，比值与温度无关，
所以没有随温度的对角线。要得到 T 分辨的比值，需要对应温度的轨迹测
`std(ΔU_model)`；当前只有 300 K。
