# 外场扰动幅度 vs OFF–POLAR 模型差（2026-10-28）

问题：外场通过 `exp(-βV_ext)` 进入 q。多大的外场幅度，其逐帧能量扰动
可以和 OFF–POLAR 的模型差相当？

数据：501 帧轨迹的前 120 帧（1,152 原子，300 K）；模型差基准
`std(ΔU_OFF-POLAR) = 0.356 eV`（整盒）。

## 结论

- **site field**：幅度标度 **s ≈ 0.4–0.6**（即 a·kT 里 a 的 0.4–0.6 倍）
  时，场扰动与模型差同量级；当前采样用 s=1，场扰动约 0.6–1.0 eV，
  是模型差的 **1.6–2.8 倍**。
- **均匀场**：**E ≈ 0.15 V/Å** 时同量级；E=0.1 约 0.7 倍，E=0.2 约 1.35 倍。
- 三个 seed 的 site field 在同幅度下相差约 1.8 倍（0.28–0.51 eV @ s=0.5），
  所以“同量级”的窗口应理解为 **0.2–0.7 eV**，而不是单点。

## 对采样的含义

- 场扰动大于模型差，说明外场确实在驱动结构（好事：探索新构型）；
- 但重加权时若场相同，场能整体抵消，限制蒸馏的仍是模型差本身；
- 若要用“场幅度”作为扰动强度，建议覆盖 s = 0.25 / 0.5 / 1 / 2 四档
  （或均匀场 0.05 / 0.1 / 0.2 / 0.5 V/Å），这样从“小于模型差”到
  “大于模型差”都有数据。
