## 说明

- site 的 std 有场种子依赖：s=1 时三个种子 0.854/1.012/0.565 eV。
- 温度列是 σ ∝ 1/T 的换算；严格变温需要对应温度的轨迹重新测 std(ΔV)。
- JCTC 的 `V/kT` 约定下物理场强 ∝ T，σ 与 T 基本无关；不要和固定 eV 约定混用。
