# OFF23 与重加权结果：水分子质心统计试算

2026-10-28。读取已保存的 OFF23 500 ps 轨迹及501帧能量，不运行新MD，不调用POLAR模型。比较的是**OFF23轨迹的等权统计**和**同一批帧按目标/源能量差加权后的统计**；后者是POLAR目标估计，并非独立POLAR MD参考。

## 数据与分子身份

384个水、1152原子、300 K、盒长23.392×23.392×35.088 Å，固定N/V，501帧，每1 ps一帧。dump不含分子ID：按原子ID每三个组成O–H–H，以O为参考通过周期边界展开两个H，再按O质量15.999、H质量1.008计算质心。

501帧里按最近氧检查全部H：没有与编号归属不一致；按编号最大O–H距离1.120 Å，99.9分位1.057 Å。这支持该数据的质心重建，但并不等于原轨迹具有显式分子拓扑。全部输入SHA256见[summary.json](summary.json)。

z分箱40个、宽0.877 Å；距离分箱宽0.1 Å。质心对统计使用均匀参考对数，原轨迹沿z分层，尾部6–8 Å不趋近1；这是一项对统计的**归一化诊断**，不能直接把它当成均匀体相g(r)进行标量OZ反演。

相对c1候选：假设两体系使用相同只依赖位置的外势、同一理想参考、且满足所用平衡EL关系，可比较 `ln(rho_weighted/rho_OFF)` 的形状，任选一个位置消去未知常数。本试算取OFF密度最大的bin作为参考z=18.86 Å，并在两边密度均大于0.005分子/Å³的23个bin中计算相对曲线的均方根幅值约**0.167**。这是两种估计曲线之间的幅度，并非误差、精度或可信的真实c1；换参考点会改变此数字。未估计POLAR化学势，固定N与界面平衡条件也未验证，不能给绝对c1标签。

## c2为何尚不能直接比较

按40个z区间计算每帧质心数协方差。由于每帧总分子数固定，协方差对全1向量存在零模：最大残差OFF约1.7e−14、加权约4.8e−14。若以最大特征值的1e−10作数值阈值，OFF有39个、加权有34个特征值高于阈值；这些数量受阈值和浮点精度影响。特征值参与比（trace² / sum(eigenvalue²)）分别约14.47和1.63，**这是谱分布诊断，不是独立帧数或c2误差**。NVT的零模和目标权重集中意味着不能无条件求逆成巨正则c2；也不能将分层体系球平均对数直接代入均匀OZ。需要匹配的体相数据或不均匀两点响应方法及独立验证。

## 重要限制

- 最大权重约59.6%，前三帧约93.2%；改变A(x)没有改变原本501帧能量得到的权重ESS。
- MD引擎和OFF重算能量去常数后的差异标准差约0.030 eV；尚未核验到足够精度。不能把加权结果误写为已认证POLAR统计。
- 目标POLAR轨迹、目标化学势和逐原子目标力均未在本试算中使用；不存在目标精度对照。
- 液体界面会移动；固定实验室坐标的剖面还要核对平衡、平移和自相关。
