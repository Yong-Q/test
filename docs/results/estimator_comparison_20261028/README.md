# 估计器对照：g(r)、密度与多重采样率（2026-10-28）

输入：`validation/off23_500ps_water1152_2026-10-23/` 的 501 帧水轨迹和
`frames_501_total_energies.csv`（OFF23 源、POLAR 目标，300 K）。脚本：
`validation/compare_estimators_20261028.py`。

目的不是认证 c1/c2，而是在**同一组 q** 下比较不同 A(x) 估计器的统计误差，
并把“q 的热涨落”和“A 的几何关联”分开。

## 需要的 A(x)（显式）

以 N_O 个氧、盒子体积 V、O–O 距离 r_ij 为例：

```
g(r):      A_k(x) = (1/N_O) * sum_{i<j} 1[r_k <= r_ij < r_{k+1}] / (4*pi*r_k^2*dz)
密度:      A_k(x) = sum_i 1[z_i in bin k] / (Lx*Ly*dz)
力辅助:    A_k(x) = (beta/(Lx*Ly)) * sum_i F_i,z * 1[z_i < z_k]
           rho(z_k) = rho(z_min) + sum_{j<=k} A_j * dz
谱展开:    c_n = (2V/(N_O(N_O-1))) * sum_{i<j} psi_n(r_ij)
           psi_n(r) = sqrt(2/rmax) sin(n*pi*r/rmax) / (2*r*sqrt(pi))
```

## 结果（CPU 部分）

| 量 | 数值 |
|---|---:|
| g(r) 直方图块误差（5 块，均值） | **0.033** |
| g(r) 正弦谱估计块误差 | 0.132 |
| g(r) 高斯基投影（非最小二乘）块误差 | 0.029 |
| g(r) 直方图 vs 正弦谱 RMS | 3.00 |
| g(r) 直方图 vs 高斯基投影 RMS | 0.47 |
| 密度剖面计数块误差 | 0.0024 |
| 多重采样率 naive vs 控制变量 RMS | 0.015 |
| naive 多重采样率对起点 0–4 的 spread | **0.101** |

## 解释

1. **直方图是可靠基线**：0.033 的块误差远小于 g 的结构幅度（峰约 3）。
2. **正弦基不可用**：`psi_n ~ sin(kr)/r` 在硬核附近病态，60 项截断产生
   Gibbs 振荡，块误差反而放大到 0.13、与直方图 RMS 差 3.0。这不是“谱方法
   不行”，而是基函数和系数估计选错。
3. **高斯基投影**：RMS 0.47 说明“投影系数”不是最小二乘，存在系统偏差；
   其块误差 0.029 不能当作精度。
4. **多重采样率**：naive 的 m/M 比值对“每 5 帧取一帧”的起点高度敏感
   （spread 0.10，约为直方图误差的 3 倍）；控制变量能把两条曲线的 RMS 差
   压到 0.015，但不能消除起点敏感性。eq(6) 形式正确但不适合直接用于生产。

## 误差预算的含义

重加权后 A 的误差放大倍率约 `sqrt(N/ESS)`。当前 501 帧、ESS≈2.35，放大
约 14.6 倍：直方图本身的 0.033 会变成 ~0.5；再经 OZ 反演（1/S² 放大）到
c2 更差。这解释了为什么“直方图估计器够好”不等于“OFF23 能估 POLAR”。

## 力辅助密度

`--force` 模式用 20 帧（每 25 帧取一帧）的 POLAR 力，按
`dρ/dz = β⟨Σ F_z δ(z−z_i)⟩` 积分得到密度，与同帧计数密度对照；结果写入
`density.csv` 的 `rho_force` 两列。目标力必须来自 POLAR，不能用 OFF23。

结果（20 帧，CPU）：

| 量 | 数值 |
|---|---:|
| 计数 vs 力辅助 RMS | 0.188 |
| 力辅助块误差（均值） | **0.219** |
| 计数块误差（同 20 帧） | ~0.002–0.02 |

力辅助密度在这一版实现下**不可用**：块误差比计数大两个量级，低 z 区还出现
负密度（积分常数/边界与噪声累积未处理）。这不是说 de las Heras 方法无效，
而是它需要 (i) 足够多帧、(ii) 正确的积分常数与边界项、(iii) 先在硬壁/已知
密度的受控体系验收；当前 20 帧只够暴露问题，不够做定量对照。

## 下一步

- 谱方法按 Patrone 的正交基 + 最小二乘系数重写，否则直接用直方图。
- 多重采样率只保留控制变量版本，并报告 q、A、qA 的自相关时间。
- 力辅助密度先在受控体系（硬壁/已知 ρ）验收，再用于 slab；当前 20 帧结果
  是负面结果，不能作为 c1 的改进。
- 所有结果仍是诊断，不认证 c1/c2。
