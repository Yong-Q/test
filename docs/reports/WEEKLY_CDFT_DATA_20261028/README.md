## 需要多少轨迹？

候选温度/外场只要通过重叠和误差验证，优先从基础轨迹后处理复用；**不预先按每一个温度、外场新跑一条轨迹**。一次来源轨迹生成的多个再加权剖面相互相关，不应算成多个独立MD。

| 层级 | 总轨迹 | 每条示例 | 总动力学 | 用途 |
|---|---:|---|---:|---|
| 理论最低探索 | 6条源轨迹 | 每分子1条 | 取决于平衡与生产长度 | 仅可做初筛；不能检验副本重现性 |
| 建议基础批 | **12条源轨迹** | 每分子1个基础状态 × 2副本；0.2 ns平衡 + 1 ns生产 | **14.4 ns** | 按条件复用温度与外场，先测可覆盖范围 |
| 建议独立目标对照 | **6条 POLAR参考轨迹** | 每分子1条；示例0.1 ns平衡 + 0.2 ns生产 | **1.8 ns** | 检查复用统计是否接近目标；是否足够待定 |
| 基础 + 对照 | **18条计划轨迹** | 上述12源 + 6目标 | **16.2 ns** | 一批有限预算的起步方案 |
| 覆盖不足时扩展 | **36条源轨迹** | 每分子3个基础密度 × 2副本；每条1.2 ns | **43.2 ns** | 给体相g/c₂增加密度锚点；是否足够待验收 |

现有水0.5 ns OFF23轨迹是分层诊断，仓库没有完整restart；不能预先将它当作一条已合格的1 ns均匀体相轨迹。新增模拟只有在重叠不足、密度锚点不足、时间收敛或独立验证失败时触发。各分子的状态点、相态、力场适用域和盒大小均需选定并保存。

**教师单点评分另算：**12条基础轨迹每条保存1000帧，全部重算POLAR需要约12,000次；若每条只评100帧，需1200次，但每条重加权只能使用这100帧。36条时对应36,000次或3600次。目标外场若改变POLAR自洽极化，某些不同外场还需重新计算目标场能/力；不能仅把固定偶极代理当完整模型。

**时间口径：**源日志中的1152原子水、OFF23 FP32、1 fs 为约38.33 GPU时/ns，GPU型号未从保存日志确认。如果假设其他分子与它逐步耗时相同，12条源轨迹约552 GPU时、3卡理想并行约7.7天；36条约1656 GPU时、3卡约23天。这是情景算术，不是六分子实测；不含6条POLAR参考、教师单点、队列及重试。完整POLAR/学生势端到端速度、逐分子和状态吞吐均待测。

## 与三篇论文对比

- **PNAS 2026**：每种流体和力场500–1000个随机外场MD条件、每个至少1 ns生产；固定N下将模拟的化学势作为潜变量。[原文](https://doi.org/10.1073/pnas.2610049123)
- **PRL 2025**：Lennard-Jones均匀体相800组密度与关联训练数据；通过g/OZ获得c₂，监督Fex的Hessian。[原文](https://doi.org/10.1103/PhysRevLett.134.056103)
- **JCTC 2025**：CO₂位置—取向密度；支持信息给出每次GCMC约4×10⁶平衡试探步及5×10⁷生产试探步，并描述给定外场下320组剖面。[原文](https://doi.org/10.1021/acs.jctc.5c00484)

机械对齐时，六种分子各500–1000个外场条件意味着3000–6000个候选剖面；各800个体相条件意味着4800组；各320个位置—取向条件意味着1920组。**这不是已证明的最低需求，也不是当前还差的精确合格标签数。** 温度/外场曲线可尝试复用，但共享源轨迹；固定N/V的单个基础盒不能变出不同平均密度的均匀体相。训练与测试需按源轨迹、状态、分子和外场共同分组，避免泄露。

## 已完成与限制

- 六种分子的POLAR教师单点烟测与已有学生留出E/F评估已记录；随机近接构型不代表平衡体系。
- 一条384水、300 K的500 ps OFF23轨迹有501帧目标能量评分；经验权重ESS为2.35，去除前20帧后约1.20。实际源能量与重算的差异约0.030 eV，需核实。
- `symmetrix-polar` 部分旧页面将OFF23来源帧上 `POLAR−student` 的评分当成学生自采样ESS；此解释不成立。该仓另有50 ps学生自采样试验，但不足以替代生产验证。[采样来源说明](../STUDENT_SOURCE_MEASURE_NOTE_2026-10-27.md)
- 质心密度、质心对数和平滑估计已有试算；目标力辅助、独立POLAR参考、可靠绝对c₁和目标c₂仍待完成。
- 260 K和0.25 V/Å的水轨迹范围属于固定偶极代理的后处理波动诊断，2倍线并不保证准确，不能直接推广到另外五种分子。
