## 2018 PRL：力辅助密度

- [ ] 按作者的平衡力密度关系，写出该体系的 `A_force(z; x)`，明确分子质心、目标势总力、外力、体积、边界与积分常数。
- [ ] 在受控体系验证计数密度与力辅助密度均值、粒子数归一化及极低密度区；硬壁、约束和非周期情况要明确边界/测度项。
- [ ] 在OFF23帧上计算 `q × A_force`，其中力必须来自POLAR；不能用OFF力代替。与目标直接采样及普通计数比较误差、分块区间和目标力调用成本。
- [ ] 若目标密度、Vext、μ及理想参考满足相应平衡关系，再评估相对/绝对c₁；当前不得声称已经得到可靠c₁。

## 2021 JCP：组合不同力估计器

- [ ] 推导适合本体系的两个力辅助密度估计器，确认它们在同一目标系综估计相同物理量；不能直接混合不同网格、不同分辨率或不同粒子定义的结果。
- [ ] 比较普通计数、两种力估计器及其线性组合；组合系数用独立训练/验证时间块评估，控制拟合噪声与时间相关。
- [ ] 分别记录目标力代价、估计器方差、偏差和长期收敛；现有低ESS下，较平滑不等于较准确。

## 2017 JCP：谱展开估计g(r)

- [ ] 对均匀体相、分子质心对距离实现基函数系数的逐帧A(x)，明确无序对计数、有限N密度、截断和边界处理。
- [ ] 按相同q、相同状态和分辨率，对照直方图、谱展开的模型偏差与分块误差；基函数数目和核宽度作为敏感性参数。
- [ ] 对当前沿z明显分层的水轨迹，只把均匀参考归一化的球平均对数作为诊断；不能直接称为体相g或由标量OZ认证c₂。真正c₂需要匹配体相采样，或位置依赖的两点关联与不均匀OZ/响应处理。

## 2026 预印本：条件能量差近似

- [ ] 文献体系是601原子水合沸石中的Li传输，源轨迹来自54个伞形窗口，目标是PMF；核对其MBAR基础权重及区间条件统计，避免把同一反应坐标方法直接等同多分子质心密度。
- [ ] 在受控体系或独立POLAR参照下比较直接指数、条件高斯及条件均值近似，验证条件分布尾部、方差项和目标形状。
- [ ] 记录已有失败现象：对当前501帧，多分子密度上的条件均值/高斯近似在低密度区产生超出源样本单帧支持的峰值；这是样本支持诊断，不单独证明真实目标物理不可能。
- [ ] 对 q 的更密采样和 qA 的较稀疏采样，分别测量 q、A和qA的时间关联，联合处理共享帧协方差，比较误差与目标单点调用成本。较密存帧不能自动产生独立样本。

## 通用验收

- [ ] 对每种方法分别保存目标量、定义、输入帧与力场哈希、估计器表达式、数据来源和随机种子。
- [ ] 比较独立参照的偏差、联合时间分块不确定度、低密度/峰谷表现、计算时间及平滑/截断敏感性；不能仅根据Kish ESS、曲线平滑或bootstrap区间宣布准确。
- [ ] ESS低或构型重叠不足时，考虑新的学生势/校正势采样、适当中间态或偏置采样；补算旧构型能量不会产生未采到的目标构型。MBAR允许未采样目标态，但要求实际采样分布覆盖它。
